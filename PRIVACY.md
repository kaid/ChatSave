# Privacy Policy

Effective date: June 18, 2026

Chat Save is a Chrome extension that exports the currently open ChatGPT
conversation to a local Markdown file.

## Data Processed

Chat Save may process the following data only when you use the extension on a
ChatGPT conversation page:

- The current ChatGPT conversation content.
- Conversation metadata returned by ChatGPT's same-origin conversation API.
- Attachment names and basic attachment metadata included in the conversation
  response.
- The ChatGPT access token already present in the page context, used only to
  request the current conversation from ChatGPT.

## How Data Is Used

The data is used only to generate a Markdown export file on your device.

Chat Save does not:

- Sell user data.
- Share user data with third parties.
- Use user data for advertising.
- Track browsing history outside supported ChatGPT pages.
- Send conversation content to any server operated by the extension developer.
- Run analytics or telemetry.

## Data Storage

Chat Save does not store conversation data on external servers.

When you export a conversation, the Markdown file is saved locally to the
location you choose in your browser. Any conversation data handled during export
is processed in the browser for that export action.

## Network Requests

Chat Save makes same-origin requests to ChatGPT endpoints on `chatgpt.com` or
`chat.openai.com` to retrieve the currently open conversation. These requests
are made to ChatGPT, not to servers operated by the extension developer.

## Contact

For questions about this privacy policy, contact the extension publisher through
the support information provided on the Chrome Web Store listing or the project
repository.
